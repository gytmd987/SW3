# 둘이서 하나비 (花火)

둘이서 하는 협력 카드 게임 하나비를 웹에서 할 수 있게 만든 한 페이지짜리 게임.

- `hanabi.html` — 게임 본문 (Claude 아티팩트로 올리는 원본)
- `index.html` — 브라우저에서 바로 여는 버전 (`./build.sh`로 `hanabi.html`에서 생성)

## 플레이 방식
- **각자 폰으로 (온라인)**: Claude 아티팩트 링크에서만 동작. 두 사람이 같은 링크로 들어와 자리에 앉으면 시작.
- **한 폰으로 같이**: 어디서든 동작. 차례가 끝날 때마다 화면이 가려지고 폰을 넘겨 주면 된다.

규칙은 게임 안 "규칙" 버튼에서 볼 수 있다.
