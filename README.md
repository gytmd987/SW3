# 둘이서 하나비 (花火)

둘이서 하는 협력 카드 게임 하나비를 웹에서 할 수 있게 만든 한 페이지짜리 게임.

- `hanabi.html` — 게임 본문 (Claude 아티팩트로 올리는 원본)
- `index.html` — 브라우저에서 바로 여는 버전 (`./build.sh`로 `hanabi.html`에서 생성)
- `vendor/peerjs.min.js` — 방 코드 온라인 연결에 쓰는 PeerJS 1.5.5

## 플레이 방식
- **각자 폰으로 (온라인)**
  - 일반 웹 주소(GitHub Pages 등)에서는 한 명이 방을 만들고 코드·링크를 보내면 다른 한 명이 들어온다. 두 폰은 PeerJS(WebRTC)로 직접 연결된다.
  - Claude 아티팩트 링크에서는 아티팩트의 공유 저장소로 같은 테이블에 앉는다.
- **한 폰으로 같이**: 어디서든 동작. 차례가 끝날 때마다 화면이 가려지고 폰을 넘겨 주면 된다.

규칙은 게임 안 "규칙" 버튼에서 볼 수 있다.

## 배포
`gh-pages` 브랜치에 `index.html`과 `vendor/`를 올리면 GitHub Pages로 서비스된다.
